# IVORY 💎 — Jewellery Brand Website

**IVORY** is a jewellery brand website designed to showcase elegant jewellery collections through a modern and visually appealing UI/UX design. The website combines soft pastel colours, stylish typography, product categories, and interactive hover effects to create a luxurious shopping experience.

## ✨ Features

- **Elegant Landing Page:** Features a hero section with brand messaging and jewellery imagery.
- **Navigation Bar:** Includes Products, Order, Rating, Sale, Login, and Search elements.
- **Product Categories:** Displays Earrings, Rings, Necklaces, Bracelets, and Watches.
- **Interactive Hover Effects:** Product cards and promotional banners display alternate images on hover.
- **Seasonal Promotions:** Highlights the Spring Collection and jewellery sale offers.
- **Shop Now Button:** Provides a link to an external jewellery shopping collection.
- **Contact Footer:** Displays contact information, email, and terms and conditions.
- **Stylish Visual Design:** Uses a pink, beige, and mauve colour palette with rounded corners and decorative typography.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and its content.
- **CSS3** — Handles styling, layouts, colours, spacing, and hover effects.
- **Google Fonts** — Adds decorative typography using Dancing Script.
- **Remix Icon** — Provides icons for shopping, ratings, and navigation.

## 🎨 Design Highlights

- Soft pastel backgrounds using beige, pink, and mauve shades.
- Large hero section with jewellery imagery.
- Product cards with image transitions on hover.
- Promotional banners with elegant typography.
- Clean navigation and footer layouts.
